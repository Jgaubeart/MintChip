# Mint Chip V2

Static production-ready marketing site for Mint Chip.

## Deploy
Upload all files in this folder to the root of your GitHub repo, then commit to `main`.
Vercel should use the repo root as the Root Directory.

Files:
- `index.html`
- `styles.css`
- `script.js`
- `assets/mint-chip-mark.png`

No build step is required.
